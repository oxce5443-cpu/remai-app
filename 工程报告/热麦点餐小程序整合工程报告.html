一、怎么跑起来（按顺序做）

  1. HBuilderX 打开 小程序前端/ → 右键 uniCloud-aliyun → 关联云服务空间 → 新建阿里云空间。
    不要绑旧 remai-demo（已被阿里云删除，残留绑定会报"服务空间不存在"）。
  2. 右键 uniCloud-aliyun/database/ → 上传所有 Schema（初始化 17 张表 + 索引）。
  3. uniCloud 控制台 → 云函数环境变量，按下表填（密钥只进控制台，不进代码/仓库）：
    变量说明
    ADMIN_USERNAME管理后台账号（本轮 admin）
    ADMIN_PASSWORD_SALT随机盐（32+ 字节）
    ADMIN_PASSWORD_HASHsha256(salt+密码) 迭代哈希（本轮密码 [REDACTED]，按 SALT 现算）
    ADMIN_HASH_ITERATIONS默认 10000
    ADMIN_TOKEN_SECRETHMAC token 签名密钥（高熵随机串）
    ADMIN_TOKEN_EXPIRE_MS默认 86400000（24h）
    WX_APPIDwxd608b92fed6a3f92
    WX_APPSECRET微信公众平台 → 开发设置
    WXPAY_MCH_ID / WXPAY_API_KEY / WXPAY_NOTIFY_URL微信支付三项（不接可先留空）
    SEED_ENABLEDseed 开关（第 5 步用）
  4. 上传全部云函数，含 cloudfunctions/common/ 两个公共模块：uni-id-common、uni-config-center。
  5. 设 SEED_ENABLED=true → 右键 seed 云端运行（或 node seed-data/import-seed.js）→ 灌完立刻改回 false。
    菜单/门店/轮播灌数据前为空是正常的。
  6. HBuilderX → 运行到小程序模拟器 → 微信开发者工具打开 unpackage/dist/build/mp-weixin（miniprogramRoot 已置空，直接导入产物目录）。
  7. 管理后台：cd 管理后台 && npm install && npm run dev:h5 → 浏览器开 Vite 地址（默认 5173）→ 登录 admin / [REDACTED]（以第 3 步环境变量为准）。
