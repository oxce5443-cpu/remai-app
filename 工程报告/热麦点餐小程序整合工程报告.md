# 热麦点餐小程序 · 运行手册

> 这是一份**操作手册**，不是论证文档。只讲三件事：怎么跑起来、现在到哪一步、你还要做什么。
>
> 目标产物 = **微信小程序（mp-weixin）**。管理后台是配套 H5。

---

## 一、怎么跑起来（按顺序做）

1. **HBuilderX 打开 `小程序前端/`** → 右键 `uniCloud-aliyun` → 关联云服务空间 → **新建阿里云空间**。
   ⚠️ 不要绑旧的 `remai-demo`（已被阿里云删除，残留绑定会报"服务空间不存在"）。
2. 右键 `uniCloud-aliyun/database/` → **上传所有 Schema**（初始化 17 张表 + 索引）。
3. **uniCloud 控制台 → 云函数环境变量**，按下表填（密钥只进控制台，不进代码/仓库）：

   | 变量 | 说明 |
   |------|------|
   | `ADMIN_USERNAME` | 管理后台账号（本轮：`admin`） |
   | `ADMIN_PASSWORD_SALT` | 随机盐（32+ 字节） |
   | `ADMIN_PASSWORD_HASH` | `sha256(salt + 密码)` 迭代哈希（本轮密码 `[REDACTED]`，按 SALT 现算） |
   | `ADMIN_HASH_ITERATIONS` | 默认 `10000` |
   | `ADMIN_TOKEN_SECRET` | HMAC token 签名密钥（高熵随机串） |
   | `ADMIN_TOKEN_EXPIRE_MS` | 默认 `86400000`（24h） |
   | `WX_APPID` | `wxd608b92fed6a3f92` |
   | `WX_APPSECRET` | 微信公众平台 → 开发设置 |
   | `WXPAY_MCH_ID` / `WXPAY_API_KEY` / `WXPAY_NOTIFY_URL` | 微信支付三项（不接支付可先留空） |
   | `SEED_ENABLED` | seed 开关（第 5 步用） |

4. **上传全部云函数**，含 `cloudfunctions/common/` 下两个公共模块：`uni-id-common`、`uni-config-center`。
5. 设 `SEED_ENABLED=true` → 右键 `seed` 云函数云端运行（或本地 `node seed-data/import-seed.js`）→ **灌完立刻把 `SEED_ENABLED` 改回 `false`**。
   > 菜单/门店/轮播在灌数据前为空是**正常**的。
6. HBuilderX → 运行到小程序模拟器 → 微信开发者工具打开 `unpackage/dist/build/mp-weixin`（`miniprogramRoot` 已置空，直接导入产物目录）。
7. **管理后台**：`cd 管理后台 && npm install && npm run dev:h5` → 浏览器开 Vite 输出地址（默认 5173）→ 登录（`admin` / `[REDACTED]`，以第 3 步环境变量为准）。
