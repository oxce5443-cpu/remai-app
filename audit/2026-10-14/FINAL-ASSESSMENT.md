## 剩余整改优先级

**P0 — 发布前必须完成**

- 下单事务、服务器幂等键与完整明细约束，保障请求超时/重放不造成重复或部分订单。页面复用订单只覆盖同页面范围。
- 真正隔离的阿里云环境部署与测试：公共模块、所有函数、环境变量和 schema；证明 token/权限/支付事务真正生效；服务到期与空间归属目前未知。
- 微信 API 响应验签、主动查单、取消关单/支付竞争与实际商户对账；库存不足但已收款的补偿/退款方案；真实退款流程。
- 轮换所有仍在使用且曾放入源码/历史备份的密钥，禁止 Git 上传历史凭据；新的统一 JWT 密钥仅保存在云端。

**P1 — 完整产品主流程**

- 统一 QRcode/qrcode 集合；服务器校验 store/table/code 状态，安全解析 scene 和 query，处理旧桌号/跨店缓存。当前扫码链路没有端到端验证。
- 规格与加价、包装费/配送费、优惠券/折扣服务端完整计价；现收银显示费用可能与服务器固定 0 费用不一致。
- 购物车多设备/登录合并及用户/门店范围；后台分页、会员字段映射、扩展页面（券包/权益/发票/评价等）逐项修复。
- 管理员限流、多用户角色/门店权限、操作日志、财务调整输入与事务、用户服务端注销。
- 四大主页面按真实数据逐按钮验收，之后做视觉调整；不复制奈雪资产。尚未完成全 UI 审核。
- 业务主体确认隐私/协议、用户数据保留删除、头像昵称采集新规则、资源版权和客服。
